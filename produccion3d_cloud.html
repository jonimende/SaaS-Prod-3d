Ingresá con tu cuenta Google para sincronizar tus pedidos en todos tus dispositivos.
Configurar Firebase
1Crear proyecto
Entrá a console.firebase.google.com y creá un proyecto llamado produccion-3d.
2Activar Google Sign-In
Authentication → Sign-in method → Google → Habilitar → Guardar.
3Crear Firestore
Firestore Database → Crear base de datos → Modo producción → us-east1. En Reglas pegá: allow read, write: if request.auth != null;
4Pegar configuración
